# JS OOP Lab — Interactive JavaScript OOP Studio

مشروع تعليمي عربي تفاعلي لتجربة مفاهيم البرمجة كائنية التوجه في JavaScript. يتضمن 25 مثالًا مستقلًا موزعة على خمسة موضوعات: Classes وStatic Methods وEncapsulation وInheritance وPolymorphism.

## ما الجديد في هذه النسخة؟

- صفحة HTML مستقلة لكل مثال داخل `examples/`، ويمكن فتحها من أيقونة المثال في القائمة الجانبية.
- ترتيب كل صفحة: بيانات الإدخال أولًا، ثم الكود الكامل أسفلها، ثم التشغيل.
- عند التشغيل تفتح صفحة إخراج HTML جديدة (`output.html`) في تبويب مستقل.
- صفحة الإخراج تعرض النتائج في مجموعات منفصلة عندما يتضمن المثال أكثر من كائن/نوع، وتعرض مقارنة مع آخر مثال تم تشغيله من الموضوع نفسه.
- أمثلة مقارنة مباشرة لتعدد الأشكال: Circle وRectangle وTriangle.
- ملفات CSS مستقلة للحركة، والمكونات، والتجاوب، وصفحات الأمثلة، والمقارنة، والإخراج.
- حركات وانتقالات خفيفة مع احترام إعداد `prefers-reduced-motion`.
- تصميم عربي RTL، وضع ليلي، بحث، قائمة تنقل، وواجهات متجاوبة.
- لا يستخدم المشروع `eval()` أو `new Function()` لتنفيذ إدخالات عشوائية؛ لكل مثال دالة تشغيل مخصصة وآمنة.

## الموضوعات والأمثلة

### 1. Classes — 8 أمثلة
تعريف الكلاس، إنشاء الكائن، الخصائص، الوصول إليها، الدوال، استدعاء الدوال، Constructor، والقيم الافتراضية.

### 2. Static Methods — 4 أمثلة
تعريف الدالة الساكنة، استدعاء دالة ساكنة من أخرى، استدعاؤها داخل Constructor باسم الكلاس، وباستخدام `this.constructor`.

### 3. Encapsulation — 4 أمثلة
مشكلة الخصائص العامة، الحقول الخاصة `#`، Getter وSetter، والتحقق من البيانات وتنسيقها.

### 4. Inheritance — 7 أمثلة
الوراثة البسيطة، متعددة المستويات، الهرمية، Constructor الأب الافتراضي، `super()` مع معاملات، Method Overriding، واستدعاء دالة الأب عبر `super.method()`.

### 5. Polymorphism — مثالان
تعدد الأشكال عبر وسيط الدالة، وتعدد الأشكال باستخدام المصفوفات. تشمل المقارنة نتائج الدائرة والمستطيل والمثلث.

## التشغيل

1. فك ضغط ZIP.
2. افتح `index.html` أو استخدم Live Server في VS Code.
3. اختر المثال من القائمة الجانبية أو افتح صفحته المستقلة.
4. عدّل بيانات الإدخال، ثم اضغط تشغيل المثال.
5. اسمح بالنوافذ المنبثقة لهذا الموقع حتى تفتح صفحة النتائج في تبويب مستقل.
6. لتجربة المقارنة، شغّل مثالًا آخر من الموضوع نفسه؛ ستقارن صفحة الإخراج المثال الحالي بآخر مثال شغّلته.

## GitHub Pages

ارفع محتويات المجلد إلى جذر المستودع بحيث يظهر `index.html` مباشرة في الجذر، ثم فعّل `Settings → Pages → Deploy from a branch → main → /(root)`. المسارات نسبية حتى تعمل داخل مستودع Project Pages.

## ملاحظات تقنية

- حقول الإدخال تغيّر قيم المثال، أما منطقة الكود فهي للعرض والنسخ وليست محررًا عامًا لتنفيذ أي نص.
- تُحفظ نتائج التشغيل وسجل المقارنة في `localStorage` على جهاز المستخدم.
- إذا لم تُفتح صفحة النتائج، اسمح بالنوافذ المنبثقة أو استخدم Live Server.
- عند مسح بيانات الموقع، يُمسح سجل المقارنة المحلي أيضًا.

## المحاكاة البصرية والواجهة الحيوية (تحديث)

أضيفت طبقة عرض مرئي تعتمد على بيانات نتيجة المثال نفسها، وليست صورًا ثابتة أو نتائج مكتوبة مسبقًا:

- **Polymorphism:** رسم SVG للدائرة والمستطيل والمثلث وفق الأبعاد المدخلة، مع عرض المعادلة والمساحة المحسوبة لكل شكل.
- **Inheritance:** بطاقات مرئية للمركبات والسيارات الكهربائية والموظفين والأدوار المتخصصة.
- **Method overriding:** بطاقة حيوان تعرض الاسم والصوت الذي أعادته الدالة المعاد تعريفها.
- **super.method():** بطاقة ملف موظف/مدير تعرض الاسم والقسم الناتجين عن دمج تنفيذ الأب والابن.
- الرسومات تُبنى باستخدام DOM وSVG محليًا، ولا تعتمد على مكتبات خارجية أو صور تحتاج إلى اتصال بالإنترنت.
